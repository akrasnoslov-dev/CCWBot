# Project Skills

Project-copied Codex skills live here when installed with `npx skills ... --copy`.

These files are developer tooling only. The Telegram bot does not import them, and runtime code
must not depend on them.

Installed project skills:

- `md-docs`: updates or initializes README.md and AGENTS.md files. Use it when documentation
  ownership between human-facing README content and agent/developer AGENTS.md context matters.

`skills-lock.json` pins the copied skill source and content hash.
