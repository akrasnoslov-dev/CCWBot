# CCW-20 — Offline safety correction of retained Cloudflare final texts

Date: 2026-10-26. **No additional Cloudflare, Luna/OpenAI or Groq calls.** No Telegram sends and no production changes.

## Finding / fix

The original one-shot A/B test found **two** final candidate Possible Action sentences incorrectly asserting that the continuation of a latest **decline** would further diverge from a **declining** 24-hour direction. These were observed for frozen **ETH** `ev_0ab71234c9080ecc` and **SOL** `ev_4bba21dd01bc8372`. Source: `CCW20_PAIRED_MESSAGES.md`, `CCW20_CASE_RESULTS.csv`, and the numeric `reports/event-alert-review-20261016/v2_private_sanitized.json` market windows.

The final-text guard in `bot/alerting/event_text.py` now rejects an unsupported **conditional future extension → cross-period convergence/divergence/alignment** assertion and uses the evidence-specific deterministic **Possible Action** fallback already computed from the actual latest snapshot path and analysed-window move. This guard runs inside the real `bot.alerts._build_event_alert_payload` assembly, **after** the LLM schema validator, so an accepted model JSON cannot bypass the final text protection.

## Reproducible offline check

- `tests/test_event_alert_message_quality.py` directly exercises both factual cases and the final assembled Telegram text.
- `tests/test_ccw20_offline_replay.py` reads **all 20** published candidate final Situation/Action pairs, retrieves their original frozen market inputs, and passes each pair back through the application's actual final Telegram assembly. No provider API is called.
- Confirmed by these assertions: 20/20 cases reconstruct a final Situation/Action; the known two inverted conditional effects are replaced by deterministic evidence-specific observations; no conditional-extend→future-diverge/converge/align claim survives the final action guard. A legitimate monitoring question that describes both possible outcomes remains permissible.
- **Verification**: GitHub Actions CI run [#40363982320](https://github.com/akrasnoslov-dev/CCWBot/actions/runs/40363982320) succeeded with 1,637 tests passing and 3 skipped. This run precedes this documentation-only commit; confirm the current branch CI as well before accepting PR.

## Concrete verified example — ETH (`ev_0ab71234c9080ecc`)

Frozen input evidence:
- Analysed 3-hour window: **rise** (about +0.263%).
- Last observed snapshot step: **decline**.
- 24-hour direction: **decline** (about −3.785%).

Old incorrect candidate Possible Action:
> If the next observed step extends this counter-move, it may further diverge from the 24h downward direction.

**New final field values via actual final assembly safety path:**

**Situation**
> The most recent supplied snapshot reverses part of the earlier path: the latest decline runs against the net analysed-window rise.

**Possible Action**
> Watch the next observed interval for further reversal toward the decline or a return to the analysed-window rise.

The second sentence says what observation matters, without incorrectly claiming it would diverge from the 24-hour decline. The same safe pattern is checked for SOL. This is a **reprocessed stored candidate message**, not a new output generated by Cloudflare.

## What this test does not prove

This offline replay checks the published 20 previously captured final pairs and fixes the **two known factual directional inversions**. It is **not** a new A/B, not an independent human assessment, and cannot establish that no other LLM phrasing outside this set will ever be misleading. The previously measured 18/20 useful pairs and four excess duplicate pairs were measured **before this correction** and must not be relabelled as fresh post-correction quality scores without rescoring. It does not validate live provider reliability, production performance, release acceptance or the separate CCW-349 cooldown changes.

**Decision:** preserve the candidate's demonstrated improvements but keep PR #377 under review; do not merge to `main` or deploy from this offline evidence alone.
